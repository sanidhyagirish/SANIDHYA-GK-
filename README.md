# Sanidhya Girish | Student Portfolio

A responsive student portfolio website made with plain HTML, CSS, and JavaScript. It is beginner-friendly and can be hosted free using GitHub Pages.

## Files
- `index.html` – website content
- `style.css` – colours, layout, and responsive design
- `script.js` – mobile navigation and current year

## Before publishing
1. Open `index.html`.
2. Replace `your.email@example.com` with your email address.
3. Replace the GitHub and LinkedIn links with your profile URLs.
4. Update the project descriptions and skills so they accurately reflect your work.
5. Add a resume PDF if you want, then link it from the page.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `sanidhya-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root (not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a minute or two. GitHub will show your live website URL in the Pages section.

Your URL will usually look like:
`https://YOUR-GITHUB-USERNAME.github.io/sanidhya-portfolio/`

## Run it on your device
You can open `index.html` in a browser. For editing on Android, use a code editor that can edit HTML/CSS/JS files.
